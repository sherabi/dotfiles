# README

- Copy these (except the Brewfile) as is into your $HOME directory.
- To install all the packages in my Brewfile execute: 

```bash
brew bundle install --file=/path/to/Brewfile
```
> Edit the Brewfile if you like. 
You will need certain packages in the Brewfile to make Neovim, Tmux and Bash 
work correctly.

- For neovim read the README in `
.config/nvim`. Its just 2 commands needed to get everything installed correctly for nvim
